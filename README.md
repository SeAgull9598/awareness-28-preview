# 看见自己 · 朋友测试站

独立的 28 天自我觉察网页原型，不属于心理工具箱。

- [示例体验版](https://seagull9598.github.io/awareness-28-preview/)：包含 9 条虚构记录，查看日历和报告，也可试填。
- [空白版](https://seagull9598.github.io/awareness-28-preview/blank.html)：首次打开没有预填内容或预选答案，从入营开始。

## 使用与存储

网页无需安装，手机或电脑浏览器可打开。推荐朋友用虚构内容完成入营、记录、日历、统计、导出与删除流程。

所有填写内容保存在当前设备、当前浏览器的 localStorage，两版使用不同存储键。刷新后保留，跨设备不同步，清除网站数据后丢失。营主无法在后台收集记录。没有真实微信登录、支付、AI、语音或管理后台。GitHub Pages 提供静态托管，可能处理网页访问日志；表单内容不上传。

空白是首次使用状态，已保存的自主填写不会在刷新时清空。可在「我的」中删除当前版本的全部记录，重新开始。不要在共享设备填写真实敏感信息。

## 测试范围

回顾题是非临床示例，不构成风险筛查或诊断。报告来自本地规则统计，不是 AI 解读。PDF 使用浏览器打印，可选择“存储为 PDF”；部分手机浏览器可改用系统分享/打印或电脑。

## 部署

纯静态文件，无依赖、无服务端、无密钥。GitHub Pages 使用 main 分支根目录。index.html 和 blank.html 共享界面与校验逻辑，browser-api.js 处理本地数据。未包含任何真实学员记录。
